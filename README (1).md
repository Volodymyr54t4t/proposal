# 💍 Сайт-пропозиція для Лєри від Володимира

Романтичний односторінковий сайт із кінематографічним інтро, галактичним тлом,
анімаціями, таймером стосунків, галереєю, любовним листом, екраном пропозиції з
кнопкою «Ні», що тікає, святкуванням із феєрверками та інтеграцією з Telegram.

## ✨ Можливості

- Кінематографічне інтро (GSAP)
- Галактичне 3D-тло (Three.js) + аврора + літаючі сердечка
- Фотогалерея (1.jpg, 2.jpg, 3.jpg)
- Ефект друкарської машинки (typewriter)
- Таймер стосунків у реальному часі
- Любовний лист
- Екран пропозиції з кнопкою «ТАК» та кнопкою «Ні», що тікає
- Святкування «ТАК»: феєрверки, троянди, конфеті
- Інтеграція з Telegram Bot API (дата, IP, браузер, ОС, пристрій, мова, часовий пояс, user-agent)
- Адаптивний дизайн + glassmorphism
- Музичний плеєр
- Секція Google Maps
- Віджет погоди (Open-Meteo, без ключа)
- Секція налаштувань (імена, фото, музика, місце, дата)

## 🚀 Запуск

```bash
npm install
cp .env.example .env   # впишіть свої значення
npm run dev
```

Відкрийте http://localhost:3000

## 🔧 Налаштування Telegram

1. Створіть бота у [@BotFather](https://t.me/BotFather) і отримайте `BOT_TOKEN`.
2. Дізнайтеся свій `CHAT_ID` через [@userinfobot](https://t.me/userinfobot).
3. Впишіть значення у файл `.env`:

```
BOT_TOKEN=ваш_токен
CHAT_ID=ваш_chat_id
PORT=3000
```

Коли Лєра натисне «ТАК», на ендпоінт `POST /yes` надійде запит, і бот надішле
вам повідомлення з деталями. Якщо токен не заданий — подія просто логуватиметься в консоль.
